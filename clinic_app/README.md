# تطبيق عيادة الجراحة (Flutter)

تطبيق لأندرويد وiOS لإدارة عيادة الجراحة: لوحة تحكم يومية، تسجيل المرضى، وجدولة العمليات وتحديث حالتها. البيانات بتتحفظ على الجهاز نفسه.

## التشغيل

1. ثبّت Flutter من https://docs.flutter.dev/get-started/install
2. افتح المشروع في الفولدر ده، وشغّل الأمر ده عشان يضيف ملفات أندرويد وiOS (مش هيغيّر ملفات `lib` ولا `pubspec.yaml`):
   ```
   flutter create --project-name clinic_app .
   ```
3. حمّل المكتبات:
   ```
   flutter pub get
   ```
4. شغّل التطبيق على جهاز أو محاكي:
   ```
   flutter run
   ```

## الهيكل

- `lib/main.dart`: نقطة البداية والتنقل السفلي بين الأقسام الثلاثة.
- `lib/models.dart`: تعريف المريض والعملية وحالاتها.
- `lib/store.dart`: حفظ البيانات وقراءتها من الجهاز.
- `lib/screens.dart`: شاشات لوحة التحكم والمرضى والعمليات، وشاشات الإضافة.

## ملاحظات

- البيانات التجريبية بتظهر أول مرة بس، وتقدر تمسحها من لوحة التحكم.
- لو احتجت بيانات مشتركة بين أكتر من جهاز، لازم نضيف خادم وقاعدة بيانات.
